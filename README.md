# astrbot_plugin_ignore_at

无视他人互相 @ 的消息。

## 场景

bot 开启**群聊全响应**时，别人 @ 别人（如 A 发“@B 吃饭去”）的消息也会触发 AI 回复，造成打扰。本插件检测消息中的 at 段并静默忽略这类消息。

## 功能

1. 检测消息中的 at 段目标：
   - at 目标**包含本 bot** → 正常放行（响应）
   - at 目标**仅为其他人** → 静默忽略（`stop_event`）
   - 无 at 段 → 放行（普通消息，交由默认逻辑处理）
2. 豁免机制：
   - 管理员（`ignore_admin`，默认开）
   - 手动名单（`whitelist_ids`）
3. `ignore_at_all`：是否同时忽略 @全体（默认关，即 @全体 视为面向全群的公告放行）

## 安装

将本目录复制到 AstrBot 的 `data/plugins/` 下，然后在 WebUI 插件管理中启用并重载插件。

## 配置

在 WebUI 插件管理 → 本插件 → 配置 中调整（保存后需重载插件）。详细说明见 `_conf_schema.json`。

## 注意事项

- 拦截是"静默忽略"，不会发送任何提示消息
- 同时 @ 本 bot 和他人（如 “@bot @B 一起玩”）→ 有效呼叫，放行
- 私聊消息通常不带 at 段，不受影响
- 与本机 `astrbot_plugin_anti_flood` 可同时使用：anti_flood 管刷屏与 bot 消息过滤，本插件管他人互 @ 的忽略

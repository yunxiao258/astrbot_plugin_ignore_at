# astrbot_plugin_ignore_at

无视他人互相 @ 的消息。

## 场景

bot 开启**群聊全响应**时，别人 @ 别人（如 A 发“@B 吃饭去”）的消息也会触发 AI 回复，造成打扰。本插件检测消息中的 at 段并静默忽略这类消息。

## 功能

1. 检测群消息中的 at 段目标：
   - at 目标**包含本 bot** → 正常放行（响应）
   - at 目标**仅为其他人** → 静默忽略（`stop_event`）
   - 无 at 段 → 放行（普通消息，交由默认逻辑处理）
2. 豁免机制：
   - 管理员（`ignore_admin`，默认开）
   - 手动名单（`whitelist_ids`）
3. `ignore_at_all`：是否同时忽略 @全体（默认关，即 @全体 视为面向全群的公告放行）
4. 仅监听**群聊**消息（私聊不处理）；`/atignore` 可查询拦截统计（持久化，重启不丢失）
5. **忽略排行报表**（v1.2.0）：按群记录谁最常触发忽略，`/atignore 报表` 查看本群 Top10 与互 @ 大户
6. **静默时段**（v1.2.0）：配置 `quiet_hours`（如 `23:00-07:00`，支持跨天）后，该时段内暂停拦截、全部放行；状态命令会标注当前是否处于静默中

## 指令

| 指令 | 说明 |
|------|------|
| `/atignore` | 查看拦截统计、豁免与静默时段状态（别名 `/忽略状态`） |
| `/atignore 报表` | 本群忽略排行 Top10（别名：排行 / 排行榜） |
| `/atignore 清空` | 清空累计忽略统计（管理员） |
| `/atignore 帮助` | 查看指令帮助 |

## 安装

将本目录复制到 AstrBot 的 `data/plugins/` 下，然后在 WebUI 插件管理中启用并重载插件。

## 配置

在 WebUI 插件管理 → 本插件 → 配置 中调整（保存后需重载插件）。详细说明见 `_conf_schema.json`。

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `ignore_admin` | true | 管理员豁免 |
| `whitelist_ids` | 空 | 额外豁免名单（QQ 号，英文逗号分隔） |
| `ignore_at_all` | false | 是否同时忽略 @全体 |
| `log_ignored` | true | 记录忽略日志 |
| `quiet_hours` | 空 | 静默时段 HH:MM-HH:MM（支持跨天），时段内暂停拦截 |

## 注意事项

- 拦截是"静默忽略"，不会发送任何提示消息
- 同时 @ 本 bot 和他人（如 “@bot @B 一起玩”）→ 有效呼叫，放行
- 仅监听群聊消息，私聊不受影响
- 忽略统计按"群号 + 用户"累计并随 `/atignore 报表` 展示；旧版 stats.json（仅总数）兼容读取
- 与本机 `astrbot_plugin_anti_flood` 可同时使用：anti_flood 管刷屏与 bot 消息过滤，本插件管他人互 @ 的忽略
